# 内窥镜机器人磁导航仿真

[English](README.md)

当前版本是 **clon001 八线圈仰卧版·肛门入口方向修正版**。使用 Qt Widgets＋OpenGL 原生界面，不依赖 HTML、浏览器或 WebView。

## 下载和打开

从[原 v2.1.0 Release](https://github.com/ZORE-dlfd/endoscopic-robot-magnetic-navigation/releases/tag/v2.1.0)下载完整 Windows ZIP，全部解压后，双击：

`八线圈胶囊导航软件/Magnetic_Camera_8Coil.exe`

仓库沿用原目录结构，也保留完整的 `软件/` 运行目录；下载完整仓库后可打开 `软件/Magnetic_Camera_8Coil.exe`。不要只下载 EXE，也不要在压缩包预览里直接运行；`_internal`、内置数据和第三方许可需要一起保留。接收者不需要安装 Python、Anaconda 或 Qt。

目标系统为 64 位 Windows 10/11，显卡驱动需支持 OpenGL 3.3 Core。程序未签名，不建议通过关闭安全防护来运行。已做同一台电脑上的独立中文路径、受限环境验收；尚未在另一台实体电脑或干净 Windows 虚拟机上验收。

## 本次更新

- **2026-10-18 紧凑磁源**：替换旧点偶极，采用有限绕组、有限铁芯和中心采样近似互耦。铁芯长 52 mm、直径 32 mm，绕组外径 56 mm，每路 1200 匝、±10 A。保留磁场优先电流分配，偏置场用这组验证的 8 mT；阵列整体随行，上限 0.2 m/s。机器人仍由实际磁力与转矩积分运动，不强制贴线。
- **逐路线圈参数**：侧栏列出 C1～C8 实时电流、阻性功耗与平均磁化占比；完整参数表逐路列出尺寸、匝数、线径、材料假设、电阻、布局、位置和电压。线框按假设尺寸画出铁芯与绕组。全空间场显示使用同一有限磁源响应查表加速，动力学记录来自直接积分。
- **横放与重力**：肠道按仰卧假设摆放，重力始终指向世界 −Z，大小 9.81 m/s²。电流、运动、摄像头和覆盖全部重算，不是旋转旧画面。原网格没有核验解剖方向，因此不是患者体位配准；水平网格也不是床面支撑模型。
- **修正入口方向**：进镜为“肛门入口 → 肠道深部”，退镜回到同一肛门。生成器统一使用原版确认的进镜 source，弃用方向相反的旧 CSV。生成时和加载时都核验实际起点、换向点、返回点和入口朝向，不是交换标签。
- **保留新版退镜**：滑窗密集搜索＋1.2 秒短时预测＋原 PD。每 0.4 秒决策，10°粗搜、2°细搜，在预测新增覆盖达到最优值 95% 的可行候选中优先选平滑方案。不是固定 37 方向，也不是训练过的 CNN。
- **保留显示与交互**：双视角、拖动条、风险悬停、磁场/流线/切片、图表和读数均保留。蓝色为进镜有效覆盖，橙色为退镜新增，两类面片互斥。只减速，不设中途停车等待；进退换向允许速度连续经过零，但没有等待段。

软件回放离线求解结果，不在每一帧重跑磁场与相机规划。画面是仿真相机渲染，不是真实内窥镜视频，也不控制实物机器人。

## 文件分类

- `软件/`：完整原生运行程序和第三方许可。
- `源码/`：界面与渲染 `magnetic_app`、磁驱动 `coil_simulation`、退镜规划 `retreat_planner`、测试 `tests`。
- `数据/`：当前 clon001 结果、未改动的参考原版、仿真输入与入口方向约定。
- `工具/`：生成、校验、构建和独立成品验收脚本。
- `文档/`：实现、修复说明、验证报告与当前截图；不提交重复的大型导出 CSV。
- `构建/`、`发布/`：本地依赖、缓存、备份和 ZIP，不进入 Git。

当前磁源与数据导入复现见[紧凑磁源接入说明](文档/紧凑磁源接入说明.md)。构建和验收见[构建说明](文档/构建说明.md)、[验证报告](文档/验证报告.md)。离线磁源使用现有 Anaconda 的 Numba，运行 EXE 不需要这些开发依赖。

## 真实性边界

仅铁芯尺寸由用户指定，其余为假设。八线圈采用有限绕组、均匀铁芯与近似互耦，控制器和被控对象共用同一模型，不是独立 FEM 或实测标定。平均磁化受饱和上限检查，但未模拟非线性 B–H、磁滞、温升、电感、电流变化率、人体和机械臂碰撞、肠壁接触与形变。平均总阻性功耗约 0.89～1.00 kW，仍假设理想冷却，实际连续运行尚未证实。32 mm 是铁芯直径，绕组外径为 56 mm。仿真走通不等于硬件或临床验证；几何覆盖也不等于病灶识别。
