# 内窥镜机器人磁导航仿真

[English](README.md)

当前版本是 **Qt Widgets + OpenGL 原生桌面程序**，示例为 clon001。不是把 HTML 压进 EXE，也不启动浏览器。它回放离线仿真结果，不控制实体机器人，不是实拍视频，未经临床验证。

## 启动与分享

双击 `软件\Magnetic_Camera.exe`。给别人时发送整个“软件”文件夹，包含 `_internal`；也可压成 ZIP，收件人完整解压后再运行。不需要安装 Python、Anaconda、浏览器或连接网络。

目标环境为 64 位 Windows 10 / 11，显卡驱动须支持 OpenGL 3.3 Core。程序未签名；已完成本机脱离开发环境的验收，尚未在另一台实体电脑或干净 Windows 虚拟机测试。不要为运行它关闭系统安全防护。

## 本次修改

- 只替换退镜相机角度策略：密集视场搜索 → 1.2 s 短时预测 → 原 PD 执行。
- 保留全部 3172 行、146 列运动/磁场状态、机身路径与姿态、速度、时长，以及全部进镜相机和进镜覆盖。
- 右上角“参数与公式 ↗”可选机器人运动、磁场解算、进镜摄像头、退镜摄像头，使用中文和正常数学符号，不显示 LaTeX 源码。
- 鼠标移到中心线附近，显示风险、净空、曲率、目标速度和三项限速，并联动风险图；隐藏路径或移开鼠标清除取点。
- 蓝色为进镜有效覆盖，橙色为退镜新增有效覆盖，灰色为尚未覆盖。蓝橙互斥，不把未覆盖区域断言为永远不可见。

## 新退镜策略

在机身前向 45° 锥内，以 10° 粗搜、2° 局部细搜生成候选；矩形窗口沿用 60° 垂直视场和 4:3 比例。每 0.4 s 决策，预测未来 1.2 s，保留预测收益至少为最优值 95% 的可行方案，再按角速度、角加速度和角加加速度代价选择。可比较条件性延迟换向，不把预测覆盖提前计入实际覆盖。

仍使用原逐轴 PD：角加速度 = clip(12×最短角误差 − 6×角速度, −150, 150)，每轴角速度上限 60°/s，角加速度上限 150°/s²，0.01 s 积分。只检查有限离散采样，不构成连续时间或临床安全保证。

规划提前离线完成，播放时只读取与插值轨迹。本次平均一次规划 287.6 ms，P95 389.7 ms，最大 464.4 ms；**不是每帧视频要等这些时间**。最大值超过 0.4 s 决策周期，因此也不能宣称已实现在线实时保证。借鉴滑动视场搜索，不训练 CNN。

## 边界

单病例、已知三维几何与未来机身轨迹，无真实图像反馈。关节代价较小不代表世界画面角速度峰值更低；几何可见不等于病灶可识别。磁场是既有局部模型，不是实际线圈标定后的全空间闭环系统。部分原轨迹净空非正、进退镜交界约 0.5 mm 残差保留，不据此作临床安全结论。随附第三方许可在“软件/第三方许可”；本仓库未新增项目整体许可。
