# Windows 便携软件

完整 EXE、运行依赖、配套资产及 6037 帧预测深度缓存放在 [Release](https://github.com/ZORE-dlfd/endoscopic-robot-magnetic-navigation/releases/latest) 的 `Windows-Portable-Heatmap-v3.0.0` 附件中。完整解压后双击 `Magnetic_Camera_8Coil.exe`；点击播放即可同步观看相机画面和缓存热力图。

不要单独移动 EXE；其同级的 `_internal` 和 `缓存数据` 必须保留。无需安装 Python 或启动模型服务。
