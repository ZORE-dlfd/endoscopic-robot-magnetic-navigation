# 胶囊视觉导航实验台：离线深度缓存播放版

完整解压“软件（深度缓存直接播放）”文件夹后，双击其中的 `Magnetic_Camera_8Coil.exe`。启动后显示当前帧的深度热力图，点击“播放”或按空格，热力图会随相机画面更新；拖动时间轴也可以查看对应帧。

分享时必须发送整个文件夹，至少保留同级的这三项：

- `Magnetic_Camera_8Coil.exe`：程序入口。
- `_internal`：程序依赖与仿真资产。
- `缓存数据`：6037 帧网络深度缓存，约 3.24 GB；保留其中原有子目录及文件名。

打包版固定读取 exe 所在目录下的“缓存数据”，不从发送者或接收者的 AppData 读取深度缓存。移动整个文件夹、换盘符或换用户名，不影响缓存路径。

缓存播放无需联网，无需安装 Python、Anaconda、CUDA 或启动深度服务，也不需要模型权重。界面中的“估计”“预计算”等功能属于重新推理，另需深度服务及模型环境；它们不是观看现有热力图的前提。

不要直接在压缩包内运行 exe。若热力图不显示，先检查“缓存数据”是否漏发、解压是否完整，以及 `_internal/assets` 是否被替换；缓存与随包仿真路线配套。软件面向 Windows 64 位，三维显示需要支持 OpenGL 3.3 的显卡驱动。

这是原生Qt Widgets＋OpenGL软件，不使用HTML或WebView。原双视角、播放、拖动条、风险悬停、图表、状态表与蓝橙覆盖显示保留。新增“磁铁模型”复选框：勾选显示八路线圈，取消隐藏；与“磁场箭头”独立，不影响磁场、机器人、相机和覆盖。

本版导入已完成并核算通过的 `gap20_m400_bias0p05mT_30A_full` 连续仿真，不是只换磁铁外观，也不是在播放时重新计算动力学。八线圈整体平移并转动，线圈中心、轴向及其磁场一起变换。模型刚体姿态逐帧插值，磁场显示继续采用同源有限磁源查表，避免拖动时重新积分。

路线仍从肛门进入，到肠道深部后退回肛门。风险与观察需求只减速，不主动安排等待。退镜保留密集滑窗搜索、1.2秒短时预测和原PD，不是旧37方向算法。

进镜297.68秒，退镜305.82秒；原记录中线圈包络与肠道网格的连续净距保守下界20.0298毫米。有效覆盖81.5553%，其中进镜68.1723%、退镜新增13.3831%。蓝色是进镜有效覆盖，橙色是退镜新增，灰色是未覆盖。

磁源参数：铁芯52×直径32毫米，绕组长44毫米、外径56毫米，每路1200匝；电流上限30 A，理想驱动400 V，饱和极化2.4 T。胶囊磁矩4.0 A·m²、偏置磁场0.05 mT。磁矩和散热等假设明显理想化，不代表现有小胶囊可制造。进镜峰值积分评估电流20.608 A，饱和约束占用0.98，不能据此认为还有很大余量。

20毫米指线圈包络到肠道网格，不是到胶囊中心。只有肠道避碰模型，没有人体外表面、床面、机械臂或导线碰撞模型。连续净距证书属于原仿真，回放球面插值不构成额外避碰认证。磁源仍是有限绕组、均匀铁芯和近似互耦，不是独立有限元或实物验证；未完整模拟温升、电感及磁滞。
