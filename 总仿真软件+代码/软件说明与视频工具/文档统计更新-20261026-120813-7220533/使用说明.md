# 胶囊视觉导航实验台：离线深度缓存播放版

完整解压“软件（深度缓存直接播放）”文件夹后，双击其中的 `Magnetic_Camera_8Coil.exe`。启动后显示当前帧的深度热力图，点击“播放”或按空格，热力图会随相机画面更新；拖动时间轴也可以查看对应帧。

分享时必须发送整个文件夹，至少保留同级的这三项：

- `Magnetic_Camera_8Coil.exe`：程序入口。
- `_internal`：程序依赖与仿真资产。
- `缓存数据`：与随包路线配套的模型预测深度缓存；保留其中原有子目录及文件名，帧数和体积以本次构建为准。

打包版固定读取 exe 所在目录下的“缓存数据”；从源码启动时，固定读取项目下 `软件（深度缓存直接播放）/缓存数据`。两种启动方式均不从发送者或接收者的 AppData 读取深度缓存。移动整个文件夹、换盘符或换用户名，不影响打包版的缓存路径。缓存子目录按路线签名区分；替换仿真资产后，必须一起更新对应缓存，不能把旧缓存目录改名充当新缓存。

缓存播放无需联网，无需安装 Python、Anaconda、CUDA 或启动深度服务，也不需要模型权重。界面中的“估计”“预计算”等功能属于重新推理，另需深度服务及模型环境；它们不是观看现有热力图的前提。

热力图来自深度估计模型对仿真内镜画面的实际预测，推理结果已提前保存，播放时按相机帧读取并插值。这里展示的是模型预测深度的离线回放；仿真渲染深度不作为网络预测冒充展示。本软件未接入临床内镜视频流，不具备临床实时深度估计或临床验证结论。

不要直接在压缩包内运行 exe。若热力图不显示，先检查“缓存数据”是否漏发、解压是否完整，以及 `_internal/assets` 是否被替换；缓存与随包仿真路线配套。软件面向 Windows 64 位，三维显示需要支持 OpenGL 3.3 的显卡驱动。

这是原生Qt Widgets＋OpenGL软件，不使用HTML或WebView。原双视角、播放、拖动条、风险悬停、图表、状态表与蓝橙覆盖显示保留。新增“磁铁模型”复选框：勾选显示八路线圈，取消隐藏；与“磁场箭头”独立，不影响磁场、机器人、相机和覆盖。

本版导入已完成并核算通过的 `gap20_m400_bias0p05mT_30A_full` 连续仿真，不是只换磁铁外观，也不是在播放时重新计算动力学。八线圈整体平移并转动，线圈中心、轴向及其磁场一起变换。模型刚体姿态逐帧插值，磁场显示继续采用同源有限磁源查表，避免拖动时重新积分。

路线仍从肛门进入，到肠道深部后退回肛门。新版进镜采用前瞻目标与深度融合；退镜保留原密集滑窗搜索、1.2 秒短时预测，并连续积分原 PD，承接进镜结束时的相机关节状态。风险与观察需求只减速，不主动安排等待。控制轨迹和深度融合在离线资产构建阶段生成，播放与视频导出读取配套结果，不在播放时重新求解控制或运行模型推理。

蓝色是进镜有效覆盖，橙色是退镜新增，灰色是未覆盖。新版覆盖率和分阶段统计待本次资产构建及核验完成后补充，旧版数值不作为本版结果。

`export_demo_video.py` 是源码环境下的视频导出工具，需要同一项目中的“源码”目录，以及已安装 NumPy、Pillow、PySide6、imageio 和 FFmpeg 编码支持的 Python 环境。播放 exe 无需这些环境。脚本按当前 `_internal/assets` 内容动态计算 `route_signature`，只读取本目录 `缓存数据/<当前签名>` 中的完整匹配缓存；缓存缺失或仍在构建时会报错停止。请等资产与缓存构建完成后再运行。

离线构建工具位于项目的 `工具/offline_depth`：`generate_cache.py` 根据交付回放生成模型预测深度缓存，`reproduce_insertion.py` 用于复现进镜深度融合。这些工具需要模型代码、权重及相应环境，普通观看者无需运行；传送软件时不必重新构建缓存。

视频为 1920×1080、30 fps，含两段进镜和一段退镜，共 30 秒。片段位置按当前进退镜时长选取，不固定套用旧路线秒数；左侧显示第三人称与蓝橙覆盖，右上是第一人称，右下是真实模型预测深度热力图，字幕标明进镜“前瞻目标 + 深度融合”和退镜“原搜索 + 连续 PD”。导出时 Qt 渲染窗口位于屏幕外，设置为不激活、不接受焦点；仍需可用的桌面和 OpenGL 3.3 环境。运行脚本后才会生成同目录的 `方案可行性展示_三视图.mp4`。

磁源参数：铁芯52×直径32毫米，绕组长44毫米、外径56毫米，每路1200匝；电流上限30 A，理想驱动400 V，饱和极化2.4 T。胶囊磁矩4.0 A·m²、偏置磁场0.05 mT。磁矩和散热等假设明显理想化，不代表现有小胶囊可制造。进镜峰值积分评估电流20.608 A，饱和约束占用0.98，不能据此认为还有很大余量。

20毫米指线圈包络到肠道网格，不是到胶囊中心。只有肠道避碰模型，没有人体外表面、床面、机械臂或导线碰撞模型。连续净距证书属于原仿真，回放球面插值不构成额外避碰认证。磁源仍是有限绕组、均匀铁芯和近似互耦，不是独立有限元或实物验证；未完整模拟温升、电感及磁滞。

目录：软件用于运行与分享；源码按界面、渲染、磁场和摄像头分类；数据保存回放资产与20毫米原始验证；工具保存导入及构建脚本；构建保存依赖与中间产物；文档保存验证和说明。
