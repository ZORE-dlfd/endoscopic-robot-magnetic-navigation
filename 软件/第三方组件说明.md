# 第三方组件与来源

本程序使用 Python 3.13.9、PySide6 / Shiboken6 / Qt 6.9.2、NumPy 2.3.5、PyOpenGL 3.1.10，构建工具为 PyInstaller 6.22.3。运行时还包含既有 Conda 环境带来的 MKL、OpenMP、字体、图像和系统兼容库。

`第三方许可/` 保留 Python、NumPy、PyOpenGL、PyInstaller 许可文本，以及 GNU LGPL 3.0、GPL 3.0、LGPL 2.1 原文。`组件来源.json` 记录 DLL 对应组件的版本、原包、许可标识和上游源码地址；空的 `license_files` 不表示没有许可要求。

Qt、PySide6、Shiboken6 以未修改的动态库分发。程序不额外限制为调试修改后的库而进行的反向工程。替换 ABI 兼容的动态库时需保留原目录结构，不能混用不同 Python ABI 或 Qt 主版本。

Qt 6.9.2 及 PySide6 对应源码来源：

```text
https://download.qt.io/official_releases/qt/6.9/6.9.2/submodules/qtbase-everywhere-src-6.9.2.tar.xz
https://download.qt.io/official_releases/qt/6.9/6.9.2/submodules/qtsvg-everywhere-src-6.9.2.tar.xz
https://download.qt.io/official_releases/QtForPython/pyside6/PySide6-6.9.2-src/pyside-setup-everywhere-src-6.9.2.tar.xz
```

项目源码、数据和构建脚本在原 GitHub 仓库的 `源码/`、`数据/`、`工具/`，构建方法见 `文档/构建说明.md`。本次没有为整个项目添加新的许可证。

来源记录沿用已有版本，不是完整商业许可审计；Conda 原包未附的传递依赖许可与通知仍需按各组件条款补齐，特别是 Intel 与 Microsoft 运行库。分享时保留本说明和整个第三方许可目录。
