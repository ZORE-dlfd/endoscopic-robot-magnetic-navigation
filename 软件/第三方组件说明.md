# 第三方组件与来源

本程序使用 Python 3.13.9、PySide6 / Shiboken6 / Qt 6.9.2、NumPy 2.3.5、PyOpenGL 3.1.10；构建工具为 PyInstaller 6.22.3。运行时还包含既有 Conda 环境带来的 MKL、OpenMP、字体、图像和系统兼容库。

`第三方许可` 保存已取得的 Python、NumPy、PyOpenGL、PyInstaller 许可文本，以及 GNU LGPL 3.0、GPL 3.0、LGPL 2.1 原文。`组件来源.json` 记录随包 DLL 对应组件的版本、原包地址、原包许可标识和上游源码地址。原 Conda 包未附带的许可文件没有伪造；空的 `license_files` 不表示组件没有许可要求。

Qt、PySide6、Shiboken6 使用动态 DLL，未修改其二进制。Qt / PySide6 对应的 LGPL 文本见 `第三方许可\LGPL-3.0.txt`，其引用的 GPL 原文一并保留。程序不额外限制为了调试修改后的库而进行的反向工程。替换 ABI 兼容的 Qt / PySide6 DLL 时请保留原目录结构；不要把另一种 Python ABI 或 Qt 主版本的 DLL 混入。

Qt 6.9.2 原始源码来源：

```text
https://download.qt.io/official_releases/qt/6.9/6.9.2/submodules/qtbase-everywhere-src-6.9.2.tar.xz
https://download.qt.io/official_releases/qt/6.9/6.9.2/submodules/qtsvg-everywhere-src-6.9.2.tar.xz
https://download.qt.io/official_releases/QtForPython/pyside6/PySide6-6.9.2-src/pyside-setup-everywhere-src-6.9.2.tar.xz
```

项目完整源码、数据和构建脚本位于交付根目录的“源码”“数据”“工具”中，不需要修改 HTML 来重新构建。构建方法见 `文档\构建说明.md`。

这里的来源清单不是商业发布的完整许可审计。若后续公开或商业分发，请进一步补齐 Conda 原包未附的传递依赖许可及通知，特别是 Intel 与 Microsoft 运行库，并按各组件原条款处理。不要把“软件”目录误认为没有第三方依赖的单文件 EXE。
