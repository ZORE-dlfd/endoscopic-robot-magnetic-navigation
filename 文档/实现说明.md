# 八线圈版实现范围

## 2026-10-18 紧凑磁源替换

当前默认磁源为 `finite-winding-core-coupled-v1`：52×32 mm 铁芯、1200 匝、56 mm 外径绕组、±10 A，近似计算铁芯互耦。运行时同源响应查表替代旧点偶极显示；动力学使用直接积分结果。新增逐路线圈参数和功耗显示，其余控制与相机算法保留。当前参数、数据来源和复现入口以《紧凑磁源接入说明》为准。下文关于旧解析梯度和旧磁源生成器的内容保留作历史实现说明，不代表当前磁源。

原始软件目录不修改。新工程独立放在 navigate software pt2。

## 保留

Qt Widgets＋OpenGL 界面布局、clon001 肠壁网格与风险地图、所有视图和时间轴交互、机身 Hermite 插值、姿态 SLERP、原摄像头滑窗密集搜索＋短时预测实现及 PD 参数、面积观察门槛和蓝橙互斥显示。

## 替换

机器人位置、速度、姿态及磁场状态重新从八磁源动力学积分得到。期望场与期望力只是控制需求，实际力由有界电流产生的场和梯度计算。运行时空间磁场直接按八磁源位置和电流计算，梯度使用解析式；不再用局部仿射场展示全局。

进退交接不重置机身、云台或阵列。独立进行完整进镜和退镜积分，不采用旧的弧长末值改写分段方式。终点同时检查弧长差和欧氏距离，不吸附或强制移动到终点。

进镜使用原前瞻目标及原 PD；退镜直接调用原版 dense_goals 和 select_predictive，不修改它们的搜索、收益与平滑代价逻辑。在新磁驱动状态上每 0.4 s 进行密集搜索与 1.2 s 预测，接受收益在最优值 95% 内的可行方案，再按平滑代价选择。未来机身位置使用当前磁驱动状态与实际速度沿路线做短时预测，不以预测轨迹强制移动机器人。云台保持原 0.01 s PD 积分，角速度和角加速度限制不变。相机误差与实际角速度参与 1.0～1.25 减速系数，未安排等待。覆盖使用同一 OpenGL 遮挡/像素可见性评估器，在新回放姿态上每 0.1 s 重算，累计观察 0.4 s 才计入面积。预测覆盖只在克隆上评价，不计入实际覆盖。

## 可复现

### 进镜入口的固定约定

进镜必须从肛门进入。生成器只使用原版确认的 source，不再使用方向相反的旧 trajectory_state.csv。原始入口与深部终点坐标固定在 `数据/仿真输入/route_direction.json`，生成前检查，积分后核验四个阶段端点，程序加载时再次核验实际三阶段位置及入口朝向。详见 `肛门入口方向修复.md`。弧长 0 为肛门，进镜增加、退镜减少；UI 路线、风险、姿态和相机参考必须与控制使用同一个 source。

### 仰卧姿态更新

原始 STL 的解剖方向没有经过核验。新版把“仰卧”作为明确的仿真摆位假设：对肠壁、路线、世界空间参考状态、法向和相机姿态施加同一刚体变换，旧 X 保持为世界 X，旧 Z 转为世界负 Y，旧 Y 转为世界 Z。源文件保留，始终从原始参考生成，拒绝重复旋转已带 patientPosture 的数据。

世界 Z 竖直向上，重力固定为 (0, 0, −9.81) m/s²，不随模型旋转。八线圈固定相对布局仍在世界正 Z 一侧；横卧后的电流、实际磁场、推进力、运动及摄像头规划全部重算，不旋转旧轨迹冒充新动力学。世界向量按 Rv 变换，姿态按 RQ 变换，梯度按 RGRᵀ 变换，机身坐标角速度与云台关节角保持不变。

水平网格 Z=0 仅作摆放参考，肠壁最低点 20 mm 是展示间距；没有添加床面支撑、组织接触或人体皮肤模型。原理想摩擦仍采用 N_eff = M × |g|，不会因为摆放横卧就擅自换成新的接触摩擦公式。

新版生成建议先写入独立暂存目录，成功后再替换正式数据：

1. `D:\anaconda\python.exe 工具\generate_eight_coil.py --destination 构建\仰卧生成\clon001`
2. `D:\anaconda\python.exe 工具\finalize_eight_coil_assets.py --assets 构建\仰卧生成\clon001`
3. 备份 `数据\clon001`，完整复制暂存目录中的结果到正式数据目录，再执行下面的测试、构建与验收。

暂存目录若已有清单，生成脚本会拒绝覆盖；可改用新的暂存目录。旧竖向数据已保存在 `构建\备份_竖向_20261017`，不会修改原始 `navigate-final software`。

使用已有 Anaconda 与复用的构建依赖，不新建环境。依次运行：

1. `D:\anaconda\python.exe 工具\generate_eight_coil.py`
2. `D:\anaconda\python.exe 工具\finalize_eight_coil_assets.py`
3. `D:\anaconda\python.exe -m pytest 源码\tests -q`
4. `D:\anaconda\python.exe 工具\build_native.py`

重新生成前若已有 magnetic_manifest.json，需要先在同一数据目录移走旧清单；生成结束后由 finalize 脚本重建校验清单。最终软件无需这些开发环境。

## 不包含

有限元、实测场标定、线圈真实尺寸设计、铁芯非线性、电感和温升、机械臂关节与碰撞、肠壁接触/形变、临床验证。示意圆环只表示点磁源位置。离线回放不是实时硬件控制。
