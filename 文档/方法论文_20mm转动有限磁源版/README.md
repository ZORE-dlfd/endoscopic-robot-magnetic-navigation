# 八线圈磁驱动与进退镜视觉协同方法论文

核对日期：2026-10-18。对象：`navigate software pt2` 当前肛门进镜、仰卧八线圈版的 clon001 有效数据。

## 文件分类
- `output/pdf/`：最终论文 PDF。
- `source/methodology.tex`：可编辑 LaTeX 主文件，图像相对路径指向 `../figures/`。
- `figures/`：六幅科研图的矢量 PDF 和预览 PNG。
- `data/`：图表原始 CSV，包括状态、电流、路线、云台及覆盖。
- `audit/`：参数与统计、输入哈希、文献核验、版式审查。
- `tools/`：复现图表、文献书目信息及 PDF 检查的脚本。
- `build/`：编译中间文件与检查图，不作为新增实验结果。

## 内容范围
机器人刚体动力学、理想摩擦、空间路径控制、风险与相机减速、八等效线圈场/梯度、电流零空间分配、进镜前瞻继承、退镜密集搜索与短时预测、几何去重覆盖、条件性闭环论证、单例结果、潜在临床意义和验证边界。

本稿不包含有限元、实物标定、神经网络训练或临床实验。闭环状态来自仿真真值；播放器为离线回放。不会把八线圈称为普遍最少数量，也不将几何覆盖等同于病灶检出率。

## 复现
Python复用 `D:\anaconda\python.exe`，依赖NumPy、Pandas、SciPy、Matplotlib，以及原项目源码和现有依赖。提取和绘图：

```powershell
& 'D:\anaconda\python.exe' '.\tools\build_evidence.py'
```

LaTeX主文件使用CTeX、Windows中文字体及常用数学排版包。可在支持中文的XeLaTeX环境中从 `source` 目录运行 `xelatex methodology.tex` 两次，或运行 `tools/compile_paper.ps1` 调用本次独立Tectonic编译器。移到其他系统时需调整 `fontset=windows`。独立编译器放在原项目 `构建/论文工具/tectonic`，未改变Anaconda环境；其缓存与临时目录使用ASCII路径，避开当前Windows版本中文缓存路径的重命名错误。

内置LaTeX预览编译器不支持随文的外部图像文件；如预览提示缺图，请使用已交付PDF或本地编译命令。源文件与六幅图必须保持相对目录关系。
