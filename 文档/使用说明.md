# 使用说明

## 启动与分享

打开 `软件\Magnetic_Camera.exe`。软件使用自己的运行库和示例数据，不需要旁边的源码、外置数据目录、原 HTML、浏览器或网络连接。

分享时完整复制“软件”目录，包括 EXE、`_internal`、使用说明及第三方许可。不要在压缩包预览窗口直接双击 EXE，先完整解压。目标为 64 位 Windows 10 / 11；显卡及驱动需要能创建 OpenGL 3.3 Core 上下文。Windows 7、32 位 Windows、某些远程桌面或虚拟显卡环境不在本次验证范围。

本程序没有代码签名，系统可能提示未知发布者。本次没有关闭系统安全设置或处理其他 EXE 的系统级启动问题。若被拦截，请先核对文件来源、哈希和安全软件报告，不要直接关闭防护。

## 播放与拖动

- 底部“播放 / 暂停”控制整条进退镜回放。空格键也可切换。
- 直接点击或拖动底部时间轴，机器人、相机、视锥和第一人称共用同一播放时间。拖动时临时暂停，松手后恢复拖动前的播放状态。
- 播放速度可选 0.25×、0.5×、1×、2×、5×、10×，默认 5×。
- 红色标记是约 299.92 s 的进镜 / 退镜分界，总时长约 634.05 s。
- “复位”或 Home 回到起点并暂停。
- 第三人称：左键旋转、右键平移、滚轮缩放、双击恢复观察角度；可切换全路径 / 跟随、实体 1× / 展示 3×。
- 鼠标移到中心线附近可显示风险、净空、曲率、目标速度及风险/净空/曲率限速，并联动风险图。移开或隐藏路径时清除；也可用“清除取点”。曲线可点击跳转；风险图横轴为弧长而不是时间。

## 覆盖颜色

勾选“已观测 / 退镜补拍”显示分区：蓝色 `#087FD1` 是进镜有效覆盖，橙色 `#F36B21` 是退镜补充的新增覆盖，灰色是尚未覆盖。蓝橙分区互斥，退镜再看到已蓝色的区域不会重复计为新增面积。灰色不代表一定永远不可见。

第一人称仍显示原有肠壁几何仿真，不把蓝橙分区伪装成真实黏膜颜色。它是实时渲染的仿真视图，不是导入的实拍视频，也不提供本次需求以外的视频编码导出功能。

## 数值与导出

右侧状态、下方统计卡片及曲线按同一时间更新；为让拖动优先流畅，文字和曲线游标约每 0.1 s 刷新一次。三维位姿不受这一频率限制。

- “导出评价 JSON”保存覆盖评价、预测配置/耗时/哈希、完整评价行及配色定义。
- “导出回放 CSV”保存 3172 行、146 列原始状态，UTF-8 BOM，适合 Excel 打开。
- 右上角“参数与公式 ↗”内可选择机器人运动、磁场解算、进镜摄像头、退镜摄像头。使用中文和正常数学符号，没有LaTeX源码。

当前只更改退镜相机角度算法。机器人运动、磁场、进镜相机和进镜覆盖未变。退镜提前离线计算，每0.4 s决策、预测1.2 s；播放器读取0.01 s轨迹，不在每帧运行规划。当前新增20,909.91 mm²，最终80.3516%。

退镜“方向射线（仅示意）20 mm”只表示目标方向，不是进镜的中心线前瞻点。原始CSV只导出保留的运动/磁场状态；新相机轨迹在内置的predictive_camera.npz，完整来源在JSON清单中。

## 出现问题时

不要从旧的 HTML 解压版 EXE 启动本版，也不要只移动本版 EXE。先确认 `_internal` 完整；如果启动报缺少 DLL，重新复制整个软件目录。

运行日志位于 `%LOCALAPPDATA%\MagneticCapsule\logs\native.log`。如果图形初始化失败，可保留日志和显卡型号用于排查，不要随意删除运行库或关闭安全软件。

较弱电脑可以先关闭磁感线、切片等附加图层，保留默认磁场箭头。性能验收是在本机完成的，其他电脑的帧率取决于显卡、驱动、分辨率和开启的图层。
