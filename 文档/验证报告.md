# clon001 原生桌面版验证报告

日期：2026-10-16。成品：`软件\Magnetic_Camera.exe`。

## 实际交付

界面由 Qt Widgets 原生控件组成，第三人称和第一人称由 OpenGL 3.3 Core 绘制，曲线由 QPainter 绘制。成品采用 EXE 加运行库目录，不打开或解压 HTML，不启动浏览器，也不依赖 Python / Anaconda 安装。运行库并非不存在，而是随“软件”目录一起提供。

保留原来页面的布局组织、双视角、机器人参数、风险和磁场图层、状态表、统计曲线、底部时间轴、公式查看及导出功能，示例依旧是 clon001（原模型标识 Colon001）。原生字体、控件度量和光照与 Three.js / Plotly 存在差异，不是逐像素复制。

进镜有效覆盖为蓝色 `#087FD1`，退镜新增有效覆盖为橙色 `#F36B21`，未覆盖 / 褶皱后为灰色。新增区域与进镜覆盖互斥，面积不按画面像素计算。

## 平滑方式

原数据的机身样本约每 0.2 s 一次，退镜相机样本约每 0.4 s 一次。显示直接逐样本切换会产生台阶感；不能据此把慢归咎于 HTML，也不能只增加中心线点数。

本版将显示与离线科学求解分开：位置使用保留端点与原速度的 Hermite 插值，机身与相对云台姿态使用最短弧 SLERP。同一连续播放时间驱动机器人、安装点、摄像头、视锥和第一人称，不为每个鼠标事件重新求解完整规划。

肠壁网格一次上传 GPU；数值与曲线游标约 0.1 s 刷新，三维位姿不受此频率限制。拖动暂停播放，松开恢复此前状态；跳转优先处理最新请求。显示插值不增加有效观察面积，不重写原来的云台约束。
