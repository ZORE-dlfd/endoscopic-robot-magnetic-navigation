# 紧凑八线圈磁源接入说明

2026-10-18。只替换磁源、对应离线轨迹和磁源参数展示；Qt/OpenGL 原生程序、路线、风险、摩擦、重力和摄像头规划不换实现。

## 现在用的磁源

| 项目 | 单路线圈假设 |
| --- | --- |
| 铁芯 | 长 52 mm，直径 32 mm |
| 绕组 | 长 44 mm，内径 34 mm，外径 56 mm |
| 匝数 / 铜线 / 含绝缘线径 | 1200 / 0.55 mm / 0.60 mm |
| 填充率 / 电阻 | 70.10% / 12.3102 Ω |
| 相对磁导率 / 饱和极化 | 2000 / 1.8 T |
| 电流 / 理想电压限制 | ±10 A / 150 V；只检查阻性压降 |
| 布局 | 方位角间隔 45°，极角交替 35°、60°，中心距交替 120、97.5 mm，朝内 |
| 阵列运动 | 相对位置固定，整体平移，上限 0.20 m/s |
| 朝向偏置磁场 | 8 mT，原点偶极版为 10 mT |

52×32 mm 是铁芯尺寸，不是含绕组外壳的尺寸。52×56 mm 保守外包络的最小线圈间距约 5.00 mm；未计算人体、外壳、电缆和机械臂碰撞。仅铁芯尺寸由用户指定，其余尚未实测。

绕组按有限长、有限厚圆形电流匝做 Biot–Savart 积分。铁芯按均匀轴向磁化的两端等效磁荷圆盘积分。退磁因子用长旋转椭球近似；各铁芯中心轴向场形成近似互耦矩阵：

`[diag(Nd + 1/(μr−1)) − C] M = H_w I`

`B = B_w I + B_core M`，梯度同样叠加。胶囊仍用 `F = Gᵀm`、`τ = m×B` 积分运动。先分配朝向磁场，再在磁场零空间尽量补足推进力；没有改变原控制策略。

## 显示与速度

侧栏 C1～C8 表随播放与拖动更新：电流、`P = RI²` 阻性功耗、平均 `|M|/Ms`。完整参数对话框逐路列出几何、材料、电气、布局、当前位置和打开时刻的动态值。

铁芯和绕组按假设尺寸绘制为线框，不是 CAD。全空间箭头、切片、流线由同一有限磁源的轴对称响应查表并双线性插值，范围到 3 m；源保守包络内不显示场，边界附近不作精度保证。动力学记录不用显示查表，而用直接磁源积分。沿实际轨迹抽样，显示与直接积分的最大场差约 0.000307 mT，梯度矩阵差约 0.0000190 T/m。这只检验数值显示近似，不能证明物理模型准确。

## 数据与结果

导入独立文件夹中已完成的紧凑磁源进退镜验证。导出时逐帧重建磁源分配，并与原记录的电流、磁场、梯度、力、转矩和速度上限逐项比较，再按原可见性与面积门槛重新评价覆盖。相机角加速度显示由保存的角速度在输出时刻求导，不改 PD 积分与角度轨迹。

- 路线每程 1722.3136 mm；进镜 295.78 s，退镜 305.42 s，共 601.20 s。
- 深部 / 返回肛门误差约 0.1215 / 0.1316 mm；最大横向误差约 0.5828 / 0.5133 mm。
- 峰值电流 10 A；平均铁芯磁化饱和占比最高约 62.73%。
- 进镜覆盖 167744.73 mm²，退镜新增 32974.75 mm²；合计 200719.47 / 246417.47 mm²，即 81.4550%。
- 退镜 764 次决策，仍为滑窗密集搜索＋1.2 s 短时预测＋原 PD；零记录约束越限、零 fallback，无计划等待。
- 平均总阻性功耗：进镜 1004.01 W、退镜 889.72 W；总阻性能量约 568.71 kJ，峰值功耗约 3.67 kW。这是显著的硬件散热负担，不应省略。

## 复现与范围

先复用已有环境。本机使用 Anaconda；离线磁源积分另用其已安装的 Numba。运行程序不需要安装 Anaconda、Numba 或 Python。

1. `工具/build_finite_field.py`：从同一有限磁源生成 `数据/clon001/finite_field.npz`。
2. `工具/integrate_compact_coils.py`：校核并导入 `数据/紧凑磁源验证` 中已完成的动力学和密集预测相机记录，重新评价覆盖。它不是从零重新优化整个实验。
3. `工具/audit_eight_coil.py` 与 `源码/tests`：核验原相机实现、路线方向、源场力学、显示近似和逐路参数。
4. `工具/build_native.py`：生成原生目录包；完整复制到 `软件` 后用 `工具/verify_native.py` 验收。

`数据/紧凑磁源验证/控制参考` 是生成该实验所用的旧版控制参考快照，不是当前默认磁源。`generate_eight_coil.py` 与 `finalize_eight_coil_assets.py` 保留旧点偶极实验复现用途，不能用它们覆盖当前默认数据。

不修改 `retreat_planner`、`camera_control`、原动力学积分和路径风险策略。控制器与被控对象仍用同一个有限磁源模型，不是独立参考 FEM；未建立温升、电感动态、磁滞、非线性 B–H、人体接触和机械臂关节约束。这里证明的是所列假设下的仿真可行性，不是实物或临床可行性的确认。
