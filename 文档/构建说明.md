# 构建与代码分布

## 已复用的环境

使用 `D:\anaconda\python.exe`：Python 3.13.9、PySide6 6.9.2、NumPy 2.3.5、pytest 8.4.2。仅把缺少的 PyOpenGL 3.1.10、PyInstaller 6.22.3 及其构建依赖安装到 `构建\依赖`，没有升级 Anaconda 里的科研库。

```powershell
$root = 'C:\Users\老白给\Desktop\navigate-final software'
& D:\anaconda\python.exe -B -m pytest "$root\源码\tests" -q
& D:\anaconda\python.exe -B "$root\源码\main.py"
& D:\anaconda\python.exe -B "$root\工具\build_native.py"
```

构建输出在 `构建\dist\Magnetic_Camera`。确认程序退出后，将输出目录的完整内容复制到“软件”，不要只复制 EXE。`工具\verify_native.py` 会把“软件”另复制到中文路径下，在只保留 Windows 系统 PATH、移除 Python / Qt / Conda 环境变量的子进程中运行成品，再检查导出和加载的模块。

```powershell
& D:\anaconda\python.exe -B "$root\工具\verify_native.py"
```

依赖目录缺失时，可按固定版本补齐，仅用于构建，不是最终用户的安装步骤：

```powershell
& D:\anaconda\python.exe -m pip install --target "$root\构建\依赖" 'PyOpenGL==3.1.10' 'PyInstaller==6.22.3'
```

本机是 Conda 版 PySide6，Qt / Shiboken DLL 位于 `Library\bin`，构建脚本会显式提供这个搜索路径。只在开发机能运行、打包后缺少 Qt DLL 的问题需要在构建阶段解决，不能让接收者安装 Anaconda 来补救。

## 源码结构

- `magnetic_app\domain\replay.py`：无损数据读取、位置插值、四元数、相机安装点、覆盖统计读取、磁场公式。
- `magnetic_app\domain\predictive.py`：校验并加载独立退镜overlay；缺失或损坏时明确报错，不静默回退。
- `magnetic_app\domain\algorithms.py`和`数据\clon001\algorithms.json`：四类可选算法说明。
- `retreat_planner`：离线密集搜索、短时预测、原PD积分、面片可见性与累计观察；不在播放循环中运行。
- `magnetic_app\domain\clock.py`：单调播放时钟、速度、拖动暂停与恢复、最新跳转优先。
- `magnetic_app\rendering\geometry.py`：网格、坐标、磁场箭头、磁感线与显示几何。
- `magnetic_app\rendering\view.py`：两个原生 OpenGL 视图、GPU 缓冲区、覆盖分区着色、观察交互。
- `magnetic_app\rendering\picking.py`和`domain\probe.py`：投影线段拾取与带单位的风险/净空/曲率/限速读数。
- `magnetic_app\ui`：原生控件、布局、QPainter 曲线和导出。
- `magnetic_app\app.py`：程序入口、异常日志、可重复的可视化验收。
- `tests`：轨迹、相机、时钟、覆盖和场几何回归测试。

## 预测退镜重算与复核

`源码\retreat_planner`是离线工具，使用现有SciPy 1.16.3；成品播放器不会导入它，也不打包SciPy。旧HTML迁移只用于历史原始数据，日常运行与本次预测重算都不读取HTML或其他项目。

```powershell
$env:PYTHONPATH = "$root\构建\依赖;$root\源码"
& D:\anaconda\python.exe "$root\工具\generate_predictive.py" --output "$root\构建\重算_预测退镜"
& D:\anaconda\python.exe "$root\工具\audit_predictive.py"
```

输出目录须是新目录，避免覆盖已有实验。全程成功且没有实际违规/fallback后，生成工具会更新`数据\clon001\predictive_camera.npz/json`；请先保留当前版本。`--seconds 8`只运行小段，不发布正式overlay。提交的正式全程记录在`文档\验证\预测退镜`。重算耗时受机器负载影响，不要求与本次毫秒统计完全一致。

轨迹清单保存原数据、生成代码及overlay的SHA256。Git属性把Python与JSON固定为LF，避免克隆时Windows换行转换破坏生成代码校验。审核工具复核原运动与进镜不变，并从正式播放器姿态重新计算逐面覆盖；未把显示帧当观察采样。

## 原数据来源与边界

`工具\migrate_data.py` 只在开发时读取原 HTML，把嵌入数组迁成 NPZ，把其余字段迁成 JSON；运行程序不调用它，也不再需要 HTML。来源与哈希在 `数据\clon001\provenance.json`。

示例沿用 clon001，原网格标识 Colon001。原始运动/磁场数据与全部进镜结果不改。位置用端点及速度约束的 Hermite 插值，机身与相对云台使用最短弧 SLERP，再从同一时刻机身重建前端安装点。预测规划与退镜评价使用同一机身位姿；有效观察仍在固定0.1 s离线采样上累计，显示帧不会增加面积。

本版保留原布局、双视角、图层、时间轴、曲线、状态、公式及导出用途，但原 Three.js / Plotly 已替换成 Qt / OpenGL / QPainter。字体度量、控件细节和光照有差异，不能称为逐像素一致的移植。
