# 构建与复验

先检查已有 Python/Anaconda 环境，能复用就复用，不必另建环境。运行发布版 EXE 不需要以下开发依赖。

本机已验证：Python 3.13.9、NumPy 2.3.5、SciPy 1.16.3、pandas 2.3.3、PySide6 6.9.2、PyOpenGL 3.1.10、pytest 8.4.2、psutil、PyInstaller 6.22.3。打包依赖可在既有环境中，也可放在忽略的 `构建/依赖/`；本仓库不包含这些依赖的开发副本。

## 源码运行与测试

在仓库根目录执行。`$python` 指向已有的兼容解释器，不要求必须装在 D 盘。

```powershell
$ErrorActionPreference = 'Stop'
$python = 'D:\anaconda\python.exe'
$root = (Get-Location).Path
$environment = Split-Path -Parent $python
$env:PYTHONIOENCODING = 'utf-8'
$env:PYTHONPATH = "$root\构建\依赖;$root\源码"
$env:PATH = "$environment\Library\bin;$environment\DLLs;$environment;" + $env:PATH
& $python -m pytest 源码/tests -q
& $python 工具/audit_eight_coil.py
& $python 源码/main.py
```

测试会读 `数据/参考原版/` 和当前 `数据/clon001/`，两者都需要保留。Qt/OpenGL 检查需要可用的图形环境。审核脚本用随仓库保存的 `数据/参考原版/planner_sha256.json` 校验六个相机核心文件，无需本机相邻的旧软件目录；摘要来自此前已确认的原版提交。审核脚本会更新本地磁源与相机逻辑核验报告。

## 重新生成

无需重算即可播放当前结果。若修改磁源、姿态或控制参数，先生成到一个新的暂存目录，不直接破坏正式数据：

```powershell
& $python 工具/generate_eight_coil.py --destination 构建/重新生成/clon001
& $python 工具/finalize_eight_coil_assets.py --assets 构建/重新生成/clon001
```

生成器使用原版确认的进镜 source，并读取 `数据/仿真输入/route_direction.json` 中的入口约定。旧 `trajectory_state.csv` 仅留作历史参考和方向回归测试，不用于本版磁驱动生成。暂存目录若已有清单，应另选目录；不要跳过方向或哈希核验。备份正式数据，再完整替换为核验后的新结果，并重新运行全部测试。

## 原生打包

```powershell
& $python 工具/build_native.py
```

新成品位于 `构建/dist/Magnetic_Camera_8Coil/`。备份后完整替换 `软件/`，不要只复制 EXE；也不要覆盖正在运行的软件。将 `文档/第三方许可/` 和第三方组件说明一并带入运行目录，再运行：

```powershell
& $python 工具/verify_native.py
```

本版为 Qt Widgets＋OpenGL 的 onedir 便携程序。ZIP 必须包含 EXE、完整 `_internal/`、数据、使用说明和第三方许可。不能做成解压 HTML 的启动器，也不能把其他 Python ABI 或 Qt 版本的 DLL 混进来。

## 旧工具的用途

`generate_predictive.py`、`audit_predictive.py` 和 `migrate_data.py` 保留用于早期理想磁场参考，不是本版八线圈联合求解入口。本版使用 `generate_eight_coil.py`、`finalize_eight_coil_assets.py` 与 `audit_eight_coil.py`。不要用旧工具覆盖当前磁驱动结果。
