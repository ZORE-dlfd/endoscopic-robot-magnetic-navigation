# 原生桌面版实现方案

用户已确认沿用原界面和 clon001 示例。原始网格的正式标识是 Colon001，界面保留用户使用的 clon001 名称。

## 目录

- 软件：可以整体复制给别人的 Windows 程序及配套运行库。
- 源码：按 domain、rendering、ui 分类的 Python/Qt 原生程序与测试。
- 数据：从原始单页文件一次性无损提取的数组、元数据、来源哈希。
- 工具：迁移、构建、验证脚本。
- 构建：打包中间文件和仅供构建使用的依赖。
- 文档：使用说明、界面对照、验证结果。

## 渲染和时间轴

使用现有 Anaconda Python、PySide6、NumPy；只补充缺少的 PyOpenGL 和 PyInstaller，放在构建依赖目录，不改科研环境的既有版本。Qt 原生控件实现界面，两个 QOpenGLWidget 分别渲染第三人称和第一人称。程序不启动浏览器，不加载 HTML、JavaScript 或 WebView。

固定肠壁网格预先上传 GPU，不在每一帧重建。播放采用单调时钟，画面只读取最新播放时间；机器人与云台共享连续时间。位置采用端点保持的 Hermite 插值，机身与相对云台分别使用最短弧四元数插值，相机安装点始终由同一时刻的机身前端重建。曲线、数值和覆盖率低频刷新，不阻塞主画面。

保留已有物理数据、前向锥角、关节限制、覆盖判定。视觉插值不是重做控制求解，也不用于给未采样时刻新增有效面积。进镜覆盖用蓝色 #087FD1，退镜补拍用橙色 #F36B21；曲线、图例与面积卡片使用同一配色。第一人称保持原有几何内窥仿真，不把覆盖颜色涂成真实黏膜，也不冒充实拍视频。

## 验证

先测试四元数、同时间相机安装点、覆盖集合互斥和总面积一致性，再测试原生窗口、导出、交互和打包启动。性能报告区分绘制耗时、交换帧间隔与实际显示器观感。不承诺其他电脑固定帧率，也不承诺未签名程序不触发系统提示。
