# 20毫米转动磁源软件

复用navigate software pt2的Qt Widgets与OpenGL程序，不改原工程。输出独立目录navi。

1. 导入gap20_m400_bias0p05mT_30A_full已完成的连续进退镜记录，不重新求轨迹或替换摄像头规划。
2. 复用原数据导出结构，原样保留路线、风险、相机姿态与覆盖首次观察时刻；换成转动八线圈位置、电流、姿态与参数。
3. 添加刚体四元数插值，位置和线圈轴向同时转动。磁源线框每帧用刚体变换绘制，磁场显示继续使用原有查表节流。
4. 新增独立“磁铁模型”复选框，不与“磁场箭头”绑定。原双视角、拖动、播放、图表、覆盖配色保留。
5. 回归测试记录一致性、旋转协变与显隐独立性，构建原生EXE并运行界面冒烟测试。

30 A电流上限、4.0 A·m²胶囊磁矩、400 V理想驱动和理想散热属于本轮方法验证假设。20毫米净距证书仅涉及肠道网格，不含人体外表面。软件是记录回放，不是实时硬件控制。
