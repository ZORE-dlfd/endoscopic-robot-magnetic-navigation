# v2.2.1 发布说明：第一人称视图远裁剪修复

日期：2026-10-20。

## 修改内容

第一人称内窥镜视图原来把 OpenGL 远裁剪面固定在 150 mm。弯曲肠段里，视线前方较深处的有效肠壁可能超过这个距离；GPU 会把这些三角面裁掉，背景色便从深处露出来，看上去像模型没有加载完整。

本版按肠道模型包围盒计算第一人称视图的远裁剪距离，并设置 2000 mm 的下限。这样只扩大相机允许绘制的深度范围，不会生成新几何，也不改变肠道数据、机器人路线、磁场、相机朝向算法、覆盖面积或运动结果。对深处画面的可见性改善取决于几何和遮挡；被前方肠壁挡住的部分仍然不会显示。

另外修正了主视图双击重置中的一行误插代码：原代码引用了该事件作用域里不存在的 `bounds`，可能导致双击时报错。增加了对应回归测试。

- 修复后的双击回归测试通过。
- 隔离启动 EXE 的 smoke 报告中，进镜/退镜主视图和第一人称视图均初始化成功，渲染错误与 Python 异常均为 0。
- 全量 UI 渲染测试未在无显示的 offscreen 环境执行；一项独立的旧姿态测试仍按其固定 Z 高差条件失败，与本版相机裁剪修改无关。
- 本次显示修复不等于对所有肠道深部的无遮挡可见保证，也不构成医疗设备或临床验证。
